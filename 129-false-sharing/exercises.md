# Exercises

## Beginner
1. False sharingคืออะไร?
2. True sharingต่างอย่างไร?
3. Data-race-free codeยัง false-shareได้ไหม?
4. Cache coherenceทำงานประมาณหน่วยใด?
5. Paddingช่วยอย่างไร?

## Intermediate
6. เพิ่ม per-line occupancy histogram.
7. เพิ่ม arbitrary thread-to-counter mapping.
8. เพิ่ม read-mostly workload.
9. เพิ่ม mixed reader/writer workload.
10. เปรียบเทียบ relaxedกับ stronger orderingโดยไม่อ้างว่า coherenceหาย.

## Advanced
11. เพิ่ม platform cache-line-size discoveryเป็น optional helper.
12. เพิ่ม CPU affinity benchmark.
13. เพิ่ม per-thread sharded counter + reduction.
14. เพิ่ม NUMA discussion/experiment.
15. ใช้ perf countersถ้ามี environmentรองรับ.

## Challenge / Research

17. เปรียบเทียบ paddingกับ sharding.
18. เชื่อม Chapter 126 alignmentและ Chapter 128 cache-line effects.
