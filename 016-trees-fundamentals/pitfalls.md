# Pitfalls — Trees Fundamentals

- saying height without declaring convention
- assuming every binary tree is balanced
- confusing full, perfect and complete
- assuming binary tree means BST
- treating left/right as unordered
- confusing empty tree with single-node tree
- assuming recursive space always O(log n)
- allowing child to have multiple parents
- creating cycles with mutable pointers
- claiming Theta(log n) solely because a structure is called a tree
