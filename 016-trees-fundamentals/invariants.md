# Invariants — Rooted Trees

1. zero or one root
2. root has no parent
3. each non-root node has exactly one parent
4. no cycles
5. every node reachable from root
6. unique root-to-node path
7. binary-tree node has at most left/right child
8. left/right positions are distinct roles
9. non-empty n-node tree has n-1 edges
