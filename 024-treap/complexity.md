# Complexity — Treap

With sufficiently random independent priority ranks:

Expected height:
    O(log n)

Expected search:
    O(log n)

Expected insert:
    O(log n)

Expected delete:
    O(log n)

Worst-case for each:
    O(n)

Rotations:
    Theta(1)

Traversal/validation:
    Theta(n)

Space:
    Theta(n)

Recursive merge/remove stack:
    O(h), expected O(log n), worst O(n).
