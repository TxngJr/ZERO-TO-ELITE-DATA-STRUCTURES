# Lab 050 — One Heap, Two Ends

Build/test:

    cmake -S . -B build
    cmake --build build
    ./build/ch050_interval_heap_tests

Tasks:
1. Insert values in random order.
2. Draw low and high embedded heaps.
3. Peek both extremes.
4. Pop min repeatedly.
5. Rebuild and pop max repeatedly.
6. Test duplicate values.
7. Compare randomized operations with a naive multiset array.
