# Lab — Intern, Bind, Shadow, Use

1. Create tables for 20,000 names and 20,000 active symbols.
2. Intern duplicate strings and compare NameId.
3. Declare 10,000 root symbols.
4. Enter nested scope.
5. Shadow selected names.
6. Verify lookup chooses inner binding.
7. Leave scope and verify outer binding restoration.
8. Build a 10,000-value def-use graph with 50,000 edges.
9. Compare per-definition use counts against independent reference.
10. Run validators and ASan/UBSan.
