# Lab 066 — Navigate Bits with Rank/Select

Build/test:

    cmake -S . -B build
    cmake --build build
    ./build/ch066_bit_vector_tests

Tasks:
1. Build bits 0101101.
2. Compute rank1 for every prefix.
3. Compute rank0.
4. Enumerate all one positions with select1.
5. Enumerate all zero positions with select0.
6. Repeat with 65 and 130 bits.
7. Inspect prefix_ones in debugger.
