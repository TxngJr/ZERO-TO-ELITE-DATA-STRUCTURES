# Course References

แหล่งอ้างอิงหลักที่ใช้เป็นแนวทางในการออกแบบหลักสูตร โดยเนื้อหาใน repository เขียนและอธิบายใหม่ ไม่คัดลอกข้อความยาวจากต้นฉบับ

- ISO C / C++ language references และ compiler documentation สำหรับ semantics, lifetime, undefined behavior และ toolchain
- cppreference สำหรับ C/C++ library/language cross-checking
- Linux man-pages สำหรับ process, allocation และ debugging interfaces
- Open Data Structures สำหรับแนวคิดโครงสร้างข้อมูลและการวิเคราะห์
- CLRS (Introduction to Algorithms) สำหรับ algorithm/data-structure theory
- The Algorithm Design Manual สำหรับ design trade-offs
- MIT / Stanford / CMU public course materials สำหรับมุมมองวิชา algorithms/systems
- CPython, Rust standard library, OpenJDK และ Go source/documentation สำหรับ chapters language internals ในช่วงท้าย

ทุก chapter มี references.md ของตัวเองเพื่อบอกว่าควรอ่านอะไรต่อจากหัวข้อนั้น
