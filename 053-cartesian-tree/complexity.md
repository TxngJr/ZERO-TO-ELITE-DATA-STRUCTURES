# Complexity — Cartesian Tree

Build:
    Theta(n)

Storage:
    Theta(n)

Direct range-min walk:
    O(h)

Worst-case height:
    Theta(n)

Random input often has much smaller expected height, but this is not a balancing guarantee.

With separate LCA preprocessing, Cartesian Trees support stronger RMQ solutions; that preprocessing is not hidden inside this chapter's direct query.
