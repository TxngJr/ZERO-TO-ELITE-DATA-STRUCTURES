# Lab 059 — Sort Every Suffix without Copying It

Build/test:

    cmake -S . -B build

1. Build SA for banana.
2. Compute inverse rank.
3. Compute LCP by hand.
4. Search "ana".
5. Inspect occurrence range.
6. Test a byte string containing zero.
7. Compare SA against naive suffix sorting.
