# Quiz — Chapter 005

1. recursion ต้องมีองค์ประกอบสำคัญอะไรบ้าง
2. base case อย่างเดียวรับประกัน termination หรือไม่
3. recursion depth เท่ากับ total calls เสมอหรือไม่
4. binary search recursion depth โตแบบใด
5. iterative binary search auxiliary space เท่าใด
6. recursive array sum auxiliary space เท่าใด
7. tail recursion รับประกัน O(1) stack ใน C/C++ หรือไม่
8. structural recursion คืออะไร
9. tree traversal time อาจ Θ(n) แต่ stack depth Θ(h) ได้หรือไม่
10. explicit stack ทำหน้าที่อะไรเมื่อแปลง DFS
11. induction เกี่ยวข้องกับ recursive correctness อย่างไร
12. loop invariant เกี่ยวข้องกับ iterative correctness อย่างไร
13. naive Fibonacci ช้าเพราะ recursion โดยตัวมันเองหรือ repeated subproblems
14. half-open interval มีข้อดีอะไร
15. stack overflow กับ heap allocation failure เป็นปัญหาเดียวกันหรือไม่
