# Exercises

## Beginner
1. Primary index ต่างจาก secondary index อย่างไร?
2. ทำไม secondary key ซ้ำได้?
3. Composite ordering `(secondary, primary)` ช่วยอะไร?
4. Range query ใช้ lower_bound อย่างไร?
5. Index แลกอะไรกับ read speed?

## Intermediate
6. เพิ่ม descending secondary scan.
7. เพิ่ม composite secondary key สอง columns.
8. เพิ่ม count-only query.
9. เพิ่ม selectivity statistics.
10. เพิ่ม covering field.

## Advanced
11. เปลี่ยน sorted arrays เป็น B+ Tree.
12. เพิ่ม update/delete maintenance.
13. วิเคราะห์ write amplification.
14. ออกแบบ MVCC-visible index entries.
15. เปรียบ secondary B+ Tree กับ LSM index.

## Challenge
16. เพิ่ม bitmap index สำหรับ low-cardinality secondary key.
17. เพิ่ม prefix-compressed secondary entries.
18. เชื่อม index นี้กับ disk pages จาก Chapter 111.
