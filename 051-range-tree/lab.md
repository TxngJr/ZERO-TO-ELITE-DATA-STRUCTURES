# Lab 051 — Search a Rectangle

Build/test:

    cmake -S . -B build
    cmake --build build
    ./build/ch051_range_tree_tests

Tasks:
1. Plot ten points manually.
2. Build the median x-tree.
3. Write y-associated lists for root and children.
4. Query one rectangle.
5. Identify canonical x-subtrees.
6. Binary-search each y list.
7. Compare reported IDs with a naive scan.
