# Lab 031 — Three Directions Per Symbol

Build/test:

    cmake -S . -B build
    cmake --build build
    ./build/ch031_tst_tests

Tasks:
1. Insert car, cat, dog, door.
2. Trace low/equal/high decisions.
3. Compare contains("ca") and has_prefix("ca").
4. Delete cat while preserving car.
5. Visit all keys lexicographically.
6. Insert binary key with zero byte.
7. Compare lookup benchmark with Trie and Radix.
