# Complexity — Balanced BST Concepts

Single rotation:
    Theta(1)

Find pivot by key:
    O(h)

Public rotate-by-key:
    O(h) + Theta(1)

Inorder/height/validate:
    Theta(n)

A self-balancing policy usually spends O(h) total path/metadata work for insert/delete while each individual rotation is constant pointer work.
