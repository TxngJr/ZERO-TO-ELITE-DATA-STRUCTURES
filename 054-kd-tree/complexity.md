# Complexity — KD-Tree

Teaching build:
    O(n log^2 n)

Storage:
    Theta(n)

Static height:
    O(log n)

2D orthogonal range reporting:
    classical O(sqrt(n)+k)

Nearest neighbor:
    branch-and-bound
    often much faster than scan
    worst-case O(n)

The benchmark demonstrates trends; it is not a complexity proof.
