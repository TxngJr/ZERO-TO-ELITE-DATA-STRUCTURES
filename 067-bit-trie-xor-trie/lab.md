# Lab 067 — Greedy XOR by Bits

Build/test:

    cmake -S . -B build
    cmake --build build
    ./build/ch067_xor_trie_tests

Tasks:
1. Insert 3, 5, 14.
2. Draw low 4-bit prefixes.
3. Query max XOR with 6.
4. Query min XOR with 6.
5. Insert duplicate 5.
6. Remove one 5.
7. Count values with XOR < 8.
